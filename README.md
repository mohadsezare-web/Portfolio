# Portfolio

A modern, responsive personal portfolio website built with **Next.js**, **React**, and **Tailwind CSS** to showcase my skills, contact information, and social media presence.

---

## 🔗 Live Demo

[See website](https://portfolio-three-kappa-92.vercel.app/)

---

## ✨ Features

- Built with **Next.js** and **React**
- **Tailwind CSS** for clean and fast styling
- Fully **responsive** design for all screen sizes
- **Dark mode / Light mode** (optional to mention if added)
- **Contact form** with input validation
- Social media links (GitHub, LinkedIn, Instagram)
- Optimized for performance and SEO


## 🛠 Technologies Used

- [Next.js](https://nextjs.org/)
- [React](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- HTML5 & CSS3
- JavaScript (ES6+)
